
# CNN 学习笔记

## 1. 卷积核在图像上的滑动

* 卷积核（Kernel）大小如 `3×3`
* 在输入图像上滑动（Stride = 1 默认）
* 每覆盖一次区域：

  * 做 **元素乘加（点积）**
  * 生成输出特征图的一个元素
* 遍历完整个图像 → 得到完整特征图
* 输出特征图空间大小计算公式：

```text
H_out = (H_in - k + 2p) / s + 1
W_out = (W_in - k + 2p) / s + 1
```

其中 k=卷积核大小, p=padding, s=stride

---

## 2. 第一层卷积示例

```python
self.l1 = nn.Conv2d(1, 32, kernel_size=(3,3))
```

* 输入通道：1（灰度图）
* 输出通道：32 → 32 个卷积核，每个独立滑动整个图像
* 输出特征图尺寸：26×26（28-3+1）
* 每个卷积核滑动操作相同，但生成的特征图不同（权重不同）

---

## 3. 第二层卷积示例

```python
self.l2 = nn.Conv2d(32, 64, kernel_size=(3,3))
```

* 输入通道：32 → 上一层的 32 张特征图
* 输出通道：64 → 64 个卷积核集合
* 每个输出通道卷积核：

  * 深度 = 32（每个输入通道都有一个 3×3 小卷积核）
  * 对每个空间位置：

    1. 每个小卷积核对对应输入通道做 3×3 点积
    2. 将 32 个结果相加
    3. 加上偏置 → 输出该位置元素
* 输出特征图尺寸 = 输入空间尺寸 - 卷积核大小 + 1（深度不影响空间尺寸）

### 核心理解

* 面积/空间大小由卷积核在空间上滑动范围决定
* 深度只影响每个输出像素的计算量和卷积参数量
* 参数量公式：

```text
参数量 = k × k × 输入通道 × 输出通道 + 偏置
```

---

## 4. 参数量对比

* 第二层卷积：32→64，3×3 卷积核

```
3×3×32×64 + 64 = 18,496 个参数
```

* 若用全连接层直接从 26×26×32 到 64 神经元：

```
26×26×32 × 64 ≈ 1,384,448 个参数
```

✅ CNN 更省参数，同时保留空间特征

---

## 5. 多通道卷积直观理解

* 卷积核是立体的（深度 = 输入通道数）
* 每个空间位置输出 = 深度方向逐元素点积 → 求和
* 空间面积不变，深度越大 → 参数越多

---

## 6. 池化层作用

* 降低空间尺寸（Downsampling）
* 提取最显著特征（Max Pooling）或区域平均特征（Average Pooling）
* 增加平移不变性
* 减少后续卷积计算量

---

## 7. 综合操作示例

```python
x = self.l1(x).relu().max_pool2d((2,2))
```

* `self.l1(x)` → 卷积得到 32 张 26×26 特征图
* `.relu()` → 非线性激活，负值变 0
* `.max_pool2d((2,2))` → 每 2×2 区域取最大值，输出 32 张 13×13 特征图
* `x` = 池化后的特征图，后续层继续操作

---

### 总结思路

1. 卷积核滑动提取局部特征 → 输出特征图
2. 输出特征图空间大小计算公式：

```text
H_out = (H_in - k + 2p) / s + 1
W_out = (W_in - k + 2p) / s + 1
```

3. 多通道卷积：深度增加参数，但空间大小不变
4. 池化层压缩空间、保留显著特征
5. ReLU 激活增加非线性
